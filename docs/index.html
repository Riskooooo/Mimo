Mimo

A desktop companion for Windows, living in a small floating pill at the top of the screen — inspired by the iOS Dynamic Island.

Mimo is designed to analyze what's happening on the computer and surface suggestions or automate small tasks for the user. The project is being built from the ground up with a focus on performance, security, and long-term maintainability — it should never be the kind of background companion that slows a machine down.

Status

Early development. The desktop shell and interaction model come first; system analysis and automation features are not built yet.

Platform

Windows only, for now.

Stack

Tauri 2 (Rust) for the native shell, Svelte and TypeScript for the interface.

Privacy

Local-first by design. No telemetry.
